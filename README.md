# Gift Video

Делает видео карточки коллекционного подарка Telegram по ссылке `https://t.me/nft/...`:
фон и символы подарка ровно как на странице t.me, анимация самого подарка и подписи «Название #номер · Модель · редкость».

**Сайт:** https://takamaqq.github.io/tg-gift-video/

Можно сразу открыть с подарком: `https://takamaqq.github.io/tg-gift-video/?gift=MoneyPot-56380`

## Что умеет

- **MP4 цикл** — 3 секунды, бесшовный. Telegram отправляет видео без звука как GIF и крутит бесконечно.
- **MP4 30 сек** — тот же цикл 10 раз подряд, для мест, где повтор не включить.
- **GIF** — 960×640, 50 fps, бесконечный.
- **PNG** — картинка карточки.
- Размер видео: 1920×1280 или 1080×720. Плашка редкости: модель / фон / символ / без плашки.

Всё рендерится прямо в браузере (WebCodecs + lottie-web), сервер не нужен. Лучше всего работает в Chrome, Edge и Safari 17+.

## Как это устроено

```
index.html, style.css     интерфейс
js/gift.js                загрузка страницы t.me/nft/<slug> и разбор данных подарка
js/card.js                отрисовка карточки (геометрия 420×280 как на t.me, масштабируется)
js/encode.js              кодирование MP4 / GIF / PNG
config.js                 адрес прокси (см. ниже)
worker/                   Cloudflare Worker — прокси для страниц t.me
dev/server.mjs            локальный сервер для разработки
```

### Зачем прокси

Telegram не разрешает браузеру читать страницы `t.me` с других сайтов (нет CORS-заголовков).
Поэтому страница подарка читается через маленький бесплатный Cloudflare Worker из папки `worker/`.
Он принимает только адреса подарков (`?slug=Name-123`), так что как открытый прокси его не использовать.
Сама анимация и картинка символа грузятся напрямую с CDN Telegram.

Если `PROXY_URL` пустой или воркер недоступен, сайт пробует публичные прокси — они работают через раз.

### Развернуть прокси

```bash
cd worker
npx wrangler login
npx wrangler deploy
```

Wrangler выведет адрес вида `https://tg-gift-proxy.<ник>.workers.dev` — впиши его в `config.js`:

```js
export const PROXY_URL = 'https://tg-gift-proxy.<ник>.workers.dev';
```

Бесплатного тарифа Cloudflare (100 000 запросов в день) хватает с запасом.

## Запуск локально

```bash
node dev/server.mjs
```

Открыть http://localhost:8787 — локальный сервер сам работает как прокси, воркер не нужен.
